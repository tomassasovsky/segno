artifacts. Flutter presentation/state-management rules do not apply.

- **Layer separation: 0 violations.** `model_geometry.py` owns component solids;
  `pcb.py` selects the portable model while generating the native board.
  Neither imports or rewrites exported package state.

  scenarios to numerical validation output. It does not drive CAD geometry or
  present those scenarios as a guarantee. No new architecture issue was found
  in that addition.
