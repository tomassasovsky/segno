# Independent adversarial review

A separate Astra-high reviewer derived literal outcomes from the accepted
contract before inspecting the author's completion claims. The final frozen
candidate passed 54 probes: 34 runtime/storage/actual-sketch groups and 20
structural model groups. Source, test harness, oracle and native-library hashes
were unchanged throughout execution.

The probes exercise real native owner receipts and refusal, complete same-owner
FX recipes, release-before-receipt, configuration retirement, numeric survivor
order, MIDI/external ownership, direct Held/Released predicates, logical latch
persistence, byte-resolution and reversed calibration, storage refusal and
rollback, malformed target aliases and preservation of valid missing targets.
Actual console firmware bytes cover detach and tip/ring reclassification.

Three verified failures were repaired without changing their reproducing
harness: an old refused external numeric cleanup overwrote a newer press;
an old activation cleanup did the same; and an old MIDI release waiter retired
a newer press of the same trigger. All three now pass with the original expected
values. Prior failing runs are retained in the private evidence archive.

One earlier fixture incorrectly expected a direct native gain write to emit a
repository eligibility notification. It was corrected to use the public mix
operation, retaining the expected release value and the original failed log.
This was a fixture correction, not a product fix. A separate historical
sensitivity experiment detects deliberately dropped low-order expression data;
it was not repeated after unrelated repairs. The current unchanged probe still
checks the 130-to-131 input transition.

## Limits

This is bounded falsification, not exhaustive proof of every session, take-lock,
reconnect, overlapping editor or action-timer permutation. Storage probes use
the actual repository transaction, not every page lifecycle. Mixed-owner
saturation and every electrical/contact-bounce condition were not tested.
Hardware without a presence contact cannot reliably distinguish an opening
from physical unplugging. UI review, aggregate tests and exact-head CI remain
separate gates. No deployment or physical hardware test occurred.
