Scope of this prototype

This study covers performance, effects, control mappings, Library and appliance setup. Prepared examples, waveforms, transport and device state are simulated. Browser persistence verifies prototype interactions; real audio processing, physical FX scales, durable media storage and Linux hardware require the production work described in the correction plan. Factory source values are retained without claiming equivalent sound.
