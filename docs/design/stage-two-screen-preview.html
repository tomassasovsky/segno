Select a track on the main screen to change the waveform close-up. Changing banks keeps that selection. The main screen shows four tracks from the active bank. Its view icon opens Track, Wave and Mixer. The small screen remains a readout while you use Settings or FX; encoder focus stays on the page you are operating. Choose a track, then press Record / Play to record. Press it again to close the loop. Undo removes one layer; hold Undo for Redo. The simulator below represents the ten physical pedals. R = Record / Play, S = Stop, U = Undo, M = Mode, 1–4 = tracks, C = Clear, B = Bank. Waveforms use real reference recordings; capture, meters and transport are simulated. No audio or hardware is connected.
