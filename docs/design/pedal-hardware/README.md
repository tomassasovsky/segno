# Pedal widget reference

The owner requested the actual hardware shape in the pedal setup comparison,
then clarified that it should be reconstructed as a reusable widget.

`pedal-hardware-widget.js` supplies the scalable vector face. Its enclosing
button owns selection, input events and encoder focus; the decorative parts
never add focus stops. The browser prototype supplies the physical label,
selected state and disabled appearance. No audio or physical switch dispatch
is implemented here.

The native Pen counterpart is **Hardware / Segno pedal face**. The accepted A
setup and new performance studies use instances with label, size and appearance
overrides. B and C remain superseded Pen references; A is the only live layout.

## Geometry and lettering

- The live **VAMP console (populated)** Fusion document supplied the case and
  top-pad measurements in `geometry.json`. The body is approximately
  76.35 × 109.87 mm, tapering toward the toe, with side hinges.
- The pad has five columns and six rows of raised grips. Its circular bases
  measure 8 mm in diameter, with 6 mm top surfaces. The widget simplifies
  lighting and bevels while preserving the arrangement and proportions.
- The label plate follows the manufacturing generator's trapezoid:
  54.359 mm at the back, 53.755 mm at the toe, and 19.90 mm long.
- `labels.json` contains outlines generated by
  `segno_enclosure._tile_ink`. Track pedals carry numbers; Record/Play and Stop
  use their physical symbols. The prototype loads these through
  `pedal-hardware-labels.js`, with no browser font dependency.
- PNGs are direct Fusion reference exports, not the UI implementation.
  `manifest.json` identifies the pedal and nameplate paired in each export.

The widget is a prototype component and a native Pen component. A production
Flutter widget is still part of the later application implementation.

## Validation

Chrome and Firefox checks cover assignment editing, independent gestures,
bank isolation, Save/Cancel, keyboard selection, visible selected state and
single-stop encoder focus. The A and C layouts were visually inspected at
1920 × 1080. Native Pen text and instance counts are recorded alongside the
exported layouts. Physical display comfort remains unverified.

Fusion export isolated visibility temporarily. Geometry, appearances and
references were not changed, and the CAD document was not saved. Assembly
visibility was restored; the viewport was returned to a top view.

## Indicators and availability

The reusable widget supplies a decorative pill indicator with independent
`color`, `active` and `disabled` inputs. The map uses the hardware's visible
60 × 6 mm lens proportions. Selection belongs to the pedal face/encoder outline;
LED illumination follows the assigned function's active state.

Momentary functions illuminate while held; toggles remain illuminated until
the next activation turns the function off. The widget does not infer either
behavior from switch edges. The main FX prototype supplies the shared function state through Stage and
provides a color palette for every physical LED in Settings → Pedals.
Normal fixed actions remain disabled, even though their LED color can be edited.

The canonical live host is [the main prototype](../fx-ux-prototype.html?review=pedal-setup).
The separate layout comparison has been retired.
